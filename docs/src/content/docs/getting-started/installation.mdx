## Requirements

- Python 3.10 or higher

## Run Without Installing (uvx)

The fastest way to use Palettize is with `uvx`, which runs the tool without permanent installation:

```bash
# Run any palettize command directly
uvx palettize show viridis
uvx palettize create viridis -f hex --steps 10
uvx palettize list presets
```

This is ideal for one-off usage, CI/CD pipelines, or trying out the tool. [uv](https://docs.astral.sh/uv/) must be installed first:

```bash
# Install uv (if not already installed)
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Install from PyPI

For regular use, install Palettize permanently:

```bash
# Using pip
pip install palettize

# Using uv (recommended)
uv pip install palettize
```

## Install from Source

To install the latest development version from GitHub:

```bash
git clone https://github.com/kovaca/palettize.git
cd palettize
pip install .
```

Or with uv:

```bash
git clone https://github.com/kovaca/palettize.git
cd palettize
uv pip install .
```

## Verify Installation

After installation, verify that Palettize is working:

```bash
palettize --version
```

You should see the version number printed to the console.

## Dependencies

Palettize automatically installs the following dependencies:

| Package | Purpose |
|---------|---------|
| [coloraide](https://github.com/facelessuser/coloraide) | Advanced color manipulation and interpolation |
| [typer](https://typer.tiangolo.com/) | CLI framework |
| [rich](https://rich.readthedocs.io/) | Terminal formatting and colors |
| [cmap](https://cmap-docs.readthedocs.io/) | Colormap presets library |
