Palettize provides a command-line interface for previewing, checking, and exporting colormaps.

## Basic Usage

```bash
palettize [OPTIONS] COMMAND [ARGS]
```

## Global Options

These options are available for all commands:

| Option | Description |
|--------|-------------|
| `--version`, `-V` | Show the application version and exit |
| `--verbose`, `-v` | Increase output verbosity. Use `-vv` for more detail |
| `--help` | Show help message and exit |

## Commands

| Command | Description |
|---------|-------------|
| [`show`](/palettize/cli/show/) | Preview a colormap in the terminal, or write a PNG or SVG |
| [`analyze`](/palettize/cli/analyze/) | Check lightness, uniformity, and color-vision safety |
| [`create`](/palettize/cli/create/) | Export a colormap, or save it as a reusable JSON file |
| [`formats`](/palettize/cli/formats/) | List export formats and the options each one accepts |
| [`list presets`](/palettize/cli/list/) | Search the preset catalog |
| [`list categories`](/palettize/cli/list/) | List preset categories |
| [`list exporters`](/palettize/cli/list/) | List export formats (same as `formats`) |
| [`presets`](/palettize/cli/list/#preset-detail) | Show one preset's metadata |
| [`info`](/palettize/cli/info/) | Show the version, links, and a banner |

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Usage error (invalid arguments) |
| `2` | Invalid color |
| `3` | Export error |
| `4` | Resource not found (preset or exporter) |
| `5` | Unexpected error |

## Color Input Formats

When specifying colors via `--colors`, you can use:

- **Named colors**: `red`, `blue`, `midnightblue`, `gold`
- **Hex colors**: `#ff0000`, `#0000ff`
- **Comma-separated lists**: `--colors "red,white,blue"` or `--colors red --colors white --colors blue`

Colors are parsed via the [ColorAide](https://github.com/facelessuser/coloraide) library, which supports many formats.

## Examples

```bash
# Show help
palettize --help

# Show version
palettize --version

# Run with verbose output
palettize -v show viridis

# Run with extra verbose output (includes tracebacks on error)
palettize -vv create viridis -f gdal -o output.txt
```
