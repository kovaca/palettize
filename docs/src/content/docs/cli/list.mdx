---
title: palettize list
description: List available presets and exporters
---

The `list` command group explores presets and export formats. `palettize formats` is the fuller view of formats: it also prints each format's options.

## List Presets

```bash
palettize list presets
palettize list presets --search blue --category sequential --limit 20
palettize list presets --namespace colorbrewer --swatch
palettize list categories
```

| Option | Short | Default | Description |
|--------|-------|---------|-------------|
| `--search` | `-q` | | Keep presets whose name contains this text. |
| `--category` | | | `sequential`, `diverging`, `cyclic`, `qualitative`, or `miscellaneous`. |
| `--namespace` | | | Filter by publisher, e.g. `colorbrewer`. |
| `--swatch` | | | Draw a gradient beside each row. |
| `--limit` | | `50` | Maximum rows. `0` shows every match. |

`palettize list categories` prints each category and how many presets it contains.

This displays a table of all preset names from the [cmap](https://cmap-docs.readthedocs.io/) library plus any custom presets.

## Preset detail

```bash
palettize presets viridis
```

Prints that preset's category, source, and a short swatch. A missing name suggests `palettize list presets --search`.

### Using Presets

Once you find a preset name, use it with `show` or `create`:

```bash
palettize show viridis
palettize create viridis -f gdal -o viridis.txt
```

### Preset Categories

Presets come from multiple sources:

- **Built-in custom presets**: Prefixed with `custom/` (e.g., `custom/grayscale`)
- **cmap library presets**: Standard scientific colormaps like `viridis`, `magma`, `inferno`, `plasma`, etc.

## List Exporters

```bash
palettize list exporters
palettize formats          # same list, plus whether each format uses --domain and --scale
palettize formats gdal     # options, types, and defaults for one format
```

Built-in identifiers: `gdal`, `qgis`, `sld`, `titiler`, `mapgl`, `observable`, `gee`, `css`, `svg`, `gimp`, `json`, `hex`, `rgba`, `hsl`.

### Using Exporters

Use the identifier (first column) with the `--format` option:

```bash
# Single format
palettize create viridis -f gdal -o output.txt

# Multiple formats
palettize create viridis -f gdal,qgis,mapgl -o "{name}_{format}.{ext}"
```

### Plugin Exporters

If you've installed additional exporter plugins, they will also appear in this list. See [Custom Exporters](/palettize/guides/custom-exporters/) for information on creating your own.
